# Jev Focus

ページ内の文章を「意味」で検索するChrome拡張です。検索バーに探したい内容を入力すると、TypeSafeのJev APIが判定して該当箇所を強調します。

## 必要なもの

- Chrome 120以上
- Node.js 22.12以上とpnpm（ビルド用）
- **TypeSafeのJev APIキー（必須）。API利用料は自分のキーに課金されます。** 詳しくは[TypeSafe公式ドキュメント](https://docs.typesafe.ai/)を参照してください。

## インストール

1. このリポジトリをcloneしてビルドします。

   ```sh
   git clone https://github.com/mgr-kb/intent-lens.git
   cd intent-lens
   pnpm install
   pnpm build
   ```

2. Chromeで `chrome://extensions` を開き、デベロッパーモードをONにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、生成された `dist/` フォルダーを選択します。
4. 拡張機能のオプション画面でAPIキーを入力し、「保存して接続」を押します。接続確認にも少量のAPI利用が発生します。

## 使い方

1. 検索したいページで拡張アイコンをクリックします。
2. バーに探したい内容を入力してEnterを押すと、該当箇所が強調されます。
3. 結果表示後のEnter / Shift+Enterで次・前の該当箇所へ移動し、Escで検索を終了します。

## 注意事項

- ONの間、そのタブの表示テキストと検索意図をJev APIへ送信します。同じタブで別サイトへ移動しても、検索を終了するまで継続します。
- APIキーはブラウザ内に平文保存されます。暗号化された専用保管庫ではありません。
